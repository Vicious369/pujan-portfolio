# pujan-portfolio

A working 3-year roadmap from self-taught security student to freelance cloud security advisor — built as a single self-contained `index.html` (fonts inlined, no external dependencies).

Live plan, not a finished résumé: honest "today" status, a certification/skill roadmap, a target service menu, and lab work — clearly separating what's real now from what's planned.

## Deploy

This is a static single-file site. To serve it via GitHub Pages:

1. Settings → Pages → Deploy from branch
2. Branch: `main`, folder: `/ (root)`
3. The site will be live at `https://vicious369.github.io/pujan-portfolio/`
